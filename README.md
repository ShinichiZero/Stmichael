# Stmichael

Offline-first progressive web app dedicated to Saint Michael the Archangel.

## Features

- Prayer to St. Michael
- Chaplet of St. Michael
- Litany
- Emergency spiritual panic button
- Large accessible controls
- Bead counter with haptic feedback
- VoiceOver-friendly live regions and controls
- ADHD-friendly focus mode
- One-line-at-a-time prayer mode
- Language support: Latin, Italian, English, German, Japanese
- Spiritual warfare mode (distraction-free dark focus prayer with ambience)
