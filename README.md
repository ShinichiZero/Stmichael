# Stmichael

Offline-first progressive web app dedicated to Saint Michael the Archangel.

## Features

- Prayer to St. Michael
- Chaplet of St. Michael
- Litany
- Premium dark UI with accessible contrast and keyboard support
- Emergency spiritual panic button with calming panel
- Bead counter with haptic feedback and persistence
- VoiceOver-friendly live regions and controls
- Focus mode for distraction-free prayer
- One-line-at-a-time prayer mode
- Language support: Latin, Italian, English, German, Japanese
- Spiritual warfare mode (intense dark focus prayer with ambience)
- Pray With Me at 3AM section with breathing, scripture, journaling, and optional audio
